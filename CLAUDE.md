# Proje Kuralları — AI Araçları Paneli

Bu, Enes'in yazılım eğitimi projesidir. Saf HTML + CSS + JavaScript ile yazılır.
Aşağıdaki kurallara **her zaman** uyulacak.

## Yasaklar
- **Production, backend, auth (kimlik doğrulama), ödeme yok.**
- **`.env` dosyası, API key, gizli anahtar yok.**
- **Yeni paket / bağımlılık kurma yok** (npm, yarn vb. yok). Ekstra kütüphane ekleme.

## Çalışma biçimi
- **Her değişiklikten önce plan ver ve onay bekle.** Onay alınmadan hiçbir dosya
  değiştirilmez.
- **Tek seferde en fazla 1-2 dosyaya dokun.** Büyük değişiklikleri küçük,
  onaylanabilir adımlara böl.
- **Console'da hata bırakma.** Yapılan değişiklik tarayıcı konsolunda hata
  (error) üretmemeli.

## Notlar
- Kod öğreticidir: değişken/fonksiyon adları ve yorumlar Türkçe, mevcut stille
  tutarlı olmalı.
- Açıklamalar sade ve adım adım olsun; kullanıcı yazılımı yeni öğreniyor.
